# Rocket-Ship 2D Game
*RocketShip is a Space Game build in Unity and C #. It is a Survial, Puzzle, space game, where player have to collect coins to make score , collect fules to fly and Land on Lander smoothly to go to next level.*

# Description
*This game can goes to different levels , till now I made upto 5 levels , I'will update the levels and make more difficult levels.*
_ _ _
*In this game there are coins, fules, landing pad , lander(rocket) , obstacles,  player have to survive by collecting fule and doughing rock terrain.*
_ _ _
*There are MainMenuScene, GameScene and GameOverScene; In MainMenuScene there are Play & Quit Button, In GameScene there are Next & Retry Button , and In GameOverScene there is Main-Menu Button*

# Goal
*Collect Fuel and Coins and Land Lander on Landing Pad and go to next level.*
## Controls:
- W & UP Arrow Key = UP Fly
- A & LEFT Arrow Key = Left Fly
- D & RIGHT Arrow Key = Right Fly
- ESC Key = Pause & Unpause
## BUILD with: 
- UNITY 2D
- C#
